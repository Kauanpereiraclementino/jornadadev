## Exercício 1 — AxCadastro × mBrowse


# a. Quando você usaria AxCadastro e quando usaria mBrowse ? Dê um exemplo de cada.
   
o AxCadastro é usado para a criaçao de cadastros simples e o mBrowse é usada para criar uma tabela de consulta e listagem de pedidos,o AxCadastro pode ser usada numa tela padrao de exclusao,alteraçao e inclusao e o mBronze se usa para quando quer apresentar uma lista de registros para consultar e navegar podendendo adicionar regras depois 

# b. Cite três coisas que o mBrowse faz e o AxCadastro não faz.

Exibir vários registros em formato de lista, facilitando a consulta dos dados.Permitir navegar pelos registros, passando de um registro para outro diretamente na tela.Permitir criar ações e customizações na consulta, como incluir botões, filtros ou funções específicas para manipular os registros exibidos.

# c. Na configuração de legendas ( aColors ), por que a regra ".T." deve ficar por último?

porque ela sempre retorna true ela funciona como uma forma padrao oara os casos anteriores nao atenderem as condiçoes ,se fosse aplicada em primeiro retornaria true em todos os casos 

# d. Qual a diferença entre um campo Virtual (X3_RELACAO) e um gatilho (SX7) para preencher o nome do cliente? 
Um campo virtual não precisa armazenar o nome do cliente fisicamente na tabela. O X3_RELACAO pode definir uma expressão que busca o nome a partir do código do cliente.
